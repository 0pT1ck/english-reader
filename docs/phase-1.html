§1

三段推进

P1 内部也风险前置

验证核心假设需要的东西，比 P1 要交付的东西少得多。先做能拿到答案的那部分。

阶段做什么为什么是这个顺序
P1a 最小验证回路：手动生成 + 本地校验 + 盲测 不接 API、不做义项、不做管线。目标是尽快知道答案
P1b 配套数据：义项集、词族与构词分解、句法结构统计、受限词汇表 都是完整功能需要的，但验证核心假设一个都用不上。假设成立后才值得投入
P1c 原计划是完整生成管线，实际做成了义项重建的尝试与生成质量收尾—— 见 Phase 1c。这一段里只完成了「接 API 自动化」 义项集补全到 7227 词；生成质量调到超纲率 0.14%、被动 15.5（真题基线 17.0）
顺延 语境释义标注与真题难度画像 → P2（分别是点词查词第一层、 真题按水平筛选的直接依赖）；过量生成择优与定点修补 → P1d 都不适合现在做：前两项的消费方在 P2，后两项在每天生成之前建等于空转

如果先花两周搞义项集和完整管线，然后发现生成的英语根本不能读，那两周全部白费，而且要回头重新想内容来源。所以顺序不能反。

§2

已定的决策

经讨论确认
议题结论
生成约束 只剩三条：词汇受限（基准词表 + 目标词）、书面语体、搭配用法正确。篇长、超纲率、专有名词数量等表面指标全部降级为参考——文章只是词汇的载体，模仿真题的各项参数是本末倒置
句法要求 只要求「正常的书面英语」，不追求精确对齐句长。但不得降级为分级读物式的简化句式——这条是设计前提，不是新增要求
难度参数化 生成难度是一组参数，不是写死的常量——这正是本项目的核心能力。两个参数必须分开：假定已掌握词（P1a 取中考+高考，约 5000）与允许用词上限（P1a 取到 CET-4，约 8800）。只准用已经会的词，文章里就没有生词可学；生词恰恰应当落在两者之间的那一层，那才是学习目标。切换目标等级时只改这两个参数
校验基准 校验器接收一个「已知词集合」，P1 阶段来自固定配置，P3 换成动态水平估计，接口不变。P1a 只验证机制能不能跑通，参数用四级标准即可，不必在边界上纠缠
来源标记 每篇生成的文章记录模型、词汇约束方案、提示词版本、生成时间。否则盲测测完只知道「有几篇被识破」，无法归因到具体模型——而选出最好的模型正是这一轮的目的
模型选择 不写死任何模型。在设置中自选、自填 API key。同时支持手动模式：系统输出提示词，用户贴到网页版 AI，再把结果贴回来
词汇约束表达 三种方案做成可切换，第一批实验一起比：完整白名单 / 描述性约束 + 难度锚点 / 纯描述性。倾向锚点方案，但用数据定
返回格式 带标记的纯文本，不用 JSON。P1a 只要标题和正文
校验器 P1a 只做本地四项、不设阈值，输出一份「体检报告」。搭配检查靠人
内容取向 易读优先：段落结构清晰、逻辑连接显式、具体优先于抽象。以说明文和议论文为主，主题不限于真题那五类
验收方式 盲测——生成文章混进真题，十几位判断者各看 3 篇，挑出哪些不是真题
§3

P1a 的工作流

手动模式

手动模式不只是省钱的备选，它顺手把最小验证回路变得更小——不接 API、不管密钥、不处理重试，系统只负责吐提示词和解析结果。而且任何模型都能试，包括没有 API 的。

1 系统生成提示词 指定目标词、约束方式（三选一）、篇数。输出一段可整体复制的文本。 系统
2 贴到网页版 AI，取回结果 每次只生成一篇，每篇开新对话。同一次生成的多篇文章措辞习惯、句式偏好、段落节奏几乎必然雷同，盲测里识破一篇会连带否掉另一篇——两篇的判断不独立，占两个名额却只有一篇的信息量。日常使用（P1c 自动模式）可以一次多篇，那时不涉及独立性问题。 人工
3 贴回系统，解析入库 解析器按标记提取，忽略前后多余的解释文字和代码块包裹。 系统
4 本地校验，出体检报告 不到一秒，无需联网。 系统
5 盲测 生成文章混进真题，发给群友判断。 人工

提示词的结构

手动模式带来一个硬约束：提示词必须短到能一次性复制。这直接否决了把 5000 词白名单整个塞进去的方案——而且两种模式必须共用同一套提示词，否则产出质量不一致，验证就白做了。

写一篇英语短文，约 350 词。

用词限制在最常见的约 5000 个英语单词以内，
大致相当于中国高中英语的水平。

难度上限参照（不要用比这些更难的词）：
achieve, benefit, community, environment, feature,
industry, method, opinion, particular, remove …

必须自然地用上（本文的学习目标）：
[目标词列表]

文体要求：说明文或议论文，正式书面语体。
段落结构清晰，逻辑连接词明确，多举具体例子。
句式保持正常书面英语的复杂度，不要刻意简化。

返回格式：
===ARTICLE===
TITLE: 标题
正文，段落之间空一行
===END===

给难度锚点而不是完整词表，理由是：模型不是约束求解器，它不会逐词回查清单。四十个词是一把它能感知的尺子，五千个词是一本它查不完的字典。漏网的超纲词交给事后校验和定点修补——那才是模型擅长的事。

校验器查什么

项目怎么查
超纲词清单词形还原 → 查词典 → 不在基准词表且非专有名词的，逐个列出
目标词命中指定的目标词有没有出现（按词条匹配）
句法结构分布依存分析统计从句、非谓语、被动、名词化等，与真题基线并列
基本指标篇长、句数、平均句长、段落数

不设阈值、不打回重试、不排序择优。标准还没校准——基准词表是拍的，句法频率刚统计出来还没验证，超纲率本身有噪音。这时候卡阈值只会误伤，而且分不清是文章的问题还是阈值的问题。第一批实验校准的不只是提示词，还有校验器本身。

一次只变一个变量

要测的其实是两样东西：模型和词汇约束方案。混在同一批里测，会发现某篇被识破却分不清是模型的问题还是方案的问题。所以分两批：

批次变量固定目的
第一批8 个模型约束方案固定用锚点方案选出模型
第二批3 种约束方案用第一批选出的模型选出方案

第二批规模小得多，而且未必需要盲测——本地校验器的超纲词数据可能就足以分出高下。实际能凑齐几个模型取决于手上有哪些账号，不足 8 个不影响设计。

盲测设计

20 篇文章 = 16 篇生成 + 4 篇真题。16 篇的构成是 8 个模型 × 2 轮，每轮一组不同的目标词、每篇独立开对话生成：同模型的两篇因此内容和风格都不同，而模型之间在同一组目标词上可比。

每位判断者随机拿 3 篇，其中最多 1 篇真题，只回答「真题 / AI 写的」。

顺序随机以防对答案。分到真题的人，那一篇同时是对他本人的校准——把真题判成 AI 写的，答卷剔除。

这一轮定位是粗筛，不是定论。参与人数事先不确定；若只有十几人，每篇生成文章平均仅被 2 人判断，不足以分辨模型之间的细微差别。但足以淘汰明显不行的：某个模型两篇都被识破，信号已经很清楚。留下 2–3 个模型后再做第二轮，每个多生成几篇，那时才谈得上分高下。两轮之间隔开，人情也用得省一些。

数据直接收集入库，不用截图回传：临时开一个公开页面，通过内网穿透发到群里，用完即关。

比总分更有价值的是分歧度：某篇 4 个人全说是 AI，它一定有明显破绽，挑出来单独分析；某篇一半一半，那是临界水平。这比一个总正确率有用得多。

§4

盲测工具独立于主程序

即用即抛

盲测页面必须无需认证——群友不可能有账号。但解法不是给主程序开一个公开入口，而是把它整个放到主程序之外。

如果做成主程序的一部分，就得引入第三类「公开路由」，还要为它划安全边界、加开关、防止以后有人往里面加东西。为一次性活动给长期架构添负担，不划算。做成独立小程序则一样都不需要：它不认识 learning.db，也没有任何路径能通到那里。

项做法
位置tools/blindtest.py——单文件，不 import 任何 backend 代码
数据独立的 data/blindtest.db，不碰主程序的三个库
素材直接读文件：生成的文章与 data/exam_papers/ 下的真题
暴露方式内网穿透临时开放，用完即关。电脑关机链接失效，短期活动无所谓
用完之后整个删掉。结果数据留着，程序不留

附带好处：它可以随便写。不受主程序的模块结构、认证约定、迁移机制约束，也不必考虑可扩展性——一次性的东西按一次性的标准写，反而更快更简单。

防止跨阶段
×接 API 自动生成——属于 P1c。P1a 全程手动，这正是它小的原因

P1a 实验结果

16 篇 · 8 个模型

第一轮：8 个模型 × 2 组目标词，全部使用锚点方案。核心假设成立，方案可行。

三条值得记住的发现

① 用词限制越狠，文章越退化成作文范文。超纲率 1.08% 那篇通篇 Moreover / In addition / On the contrary 开头、内容全是抽象论述、没有一个具体事实；超纲率 9.13% 那篇写十九世纪欧美慈善组织，有场景有细节，最接近真题。后续应把词汇限制往宽处调——长期只读前一种，接触不到真实文本里的具体名词、专名和数据表述。

② 被动偏少 + 名词化偏多 + 几乎不用形式主语，是一组 AI 写作指纹。现代模型被训练成偏好主动语态和「清晰直接」，而学术英语恰恰大量使用被动和 It is essential that…。这三项可以写进提示词加以纠正。

③ 目标词随机抽取会导致硬凑。anchor / humor / wagon / robe 八个不相关的词塞进 350 词，模型只能生硬安排（an anchor for future improvement、develop humor）。选词时应考虑语义关联，语境自然了，语境记忆的质量才高。

验收结论

语言正确性是唯一不可退让的一条——三篇逐句读过，没有搭配或用法错误，不会教错东西。目标词都用在句子里而非列表里，难度落在「读得懂但有挑战」的位置，句法有训练价值。就「能不能用来学英语」这个目标而言，方案成立。

盲测按决定跳过：它回答的是「像不像真人写的」，而这个项目要回答的是「能不能用来学」。后者可以由语言层面的检查得出结论，前者才需要真人。真题直读（B7）本身也是一层兜底——真实语料的接触由它保证。

P1a 验收清单

01 提示词能一次复制、结果能稳定解析 连续三批，解析成功率高，不需要手工修补格式。
02 三种词汇约束方案有可比的数据 超纲词数量、目标词使用是否自然，各有实测结果，能得出结论。
03 体检报告的数字合理 对照人工阅读的感受，校验器报的数没有明显偏离——这一步同时是在校准校验器。
04 盲测正确率接近随机 约 50% 说明分不出来，假设成立；60–70% 可用但值得优化；80% 以上要回去改。第一轮按模型分别看，先淘汰明显不行的。
05 本人读几篇，认可可以用来学习 最终的一票。数据再好看，读起来不能接受就是不行。
